# Guidelines for metadata files

# README.md
- adoption-focused: what it runs and how to start it, not how it's built
- the one `docker run` that matters, then the variables that change it
- no development commands -> CONTRIBUTING.md

# FAQ.md
- errors, platform questions and recipes that go beyond the quick start

# CONTRIBUTING.md
- Guidance for contributors
- AI-disclosure requirement (harness and model)
- Fully AI-generated issues and PRs welcome

# LICENSE and CREDITS.md
- LICENSE is GPL-3.0-or-later, inherited from Docker-OSX, and stays byte-for-byte
- CREDITS.md carries the fork notice and the upstream acknowledgements
